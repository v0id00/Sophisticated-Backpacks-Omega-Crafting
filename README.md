# Sophisticated Backpacks: Omega Crafting

NeoForge addon for [Sophisticated Backpacks](https://www.curseforge.com/minecraft/mc-mods/sophisticated-backpacks). Adds a single **Crafting Upgrade Omega Tier** that embeds eight workstation upgrades in one backpack slot.

## Included upgrades

- Stonecutter
- Crafting
- Smithing
- Anvil
- Advanced Jukebox
- Auto Blasting
- Auto Smelting
- Auto Smoking

The omega upgrade conflicts with installing those upgrades separately. Items stored inside sub-upgrades persist across GUI close, equip, place, and world reload.

## Requirements

| Mod | Version |
|-----|---------|
| Minecraft | 1.21.1 |
| NeoForge | 21.1+ |
| Sophisticated Core | 1.5.x |
| Sophisticated Backpacks | 3.26.x |

## Build

```bash
./gradlew build
```

Output: `build/libs/sophisticatedbackpacksomegacrafting-1.21.1-1.0.1.jar`

Copy the jar into your instance `mods/` folder.

## Recipe

Shaped crafting (nether star center):

```
SCA
BNJ
FLM
```

S = Stonecutter, C = Crafting, A = Smithing, B = Anvil, N = Nether Star, J = Advanced Jukebox, F = Auto Blasting, L = Auto Smelting, M = Auto Smoking.
